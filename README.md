# SAKUSURA — サクッとスライド

HTMLスライドの編集、PDFからのデザイン追加、発表、動画の書き出しができるローカルアプリです。ブラウザで操作し、データは自分のPCに保存します。

## 更新情報

### v1.1.0（2026-11-05）

**追加**

- 全画面発表の操作バー：マウスを動かすと左下に表示され、送り・再生・ペン・拡大などをボタンで操作できます
- レーザーポインター（`L`）とマウスカーソルの表示
- ペン（`P`）：5色の切り替え（`1`〜`5`）、1本戻す（`Ctrl`+`Z`）、スライドごとの全消去（`E`）。線は発表中だけの表示で、保存や動画の書き出しには入りません
- 拡大（`Z`・マウスホイール）：1〜4倍。拡大中はドラッグで移動できます
- スライド一覧（`G`）：サムネイルを選んで移動できます
- PDFの書き出し（1スライド1ページ、文字は選択・検索可能。`npm run pdf -- --lecture <講義名>`）
- 血液透析の回路図アニメーション（`hdCircuit`。書き方は `docs/LECTURE_FORMAT.md`）
- 同じテーマを複数のLLMで作り比べた見本4本（血液透析の仕組み）

音声付き再生中は、OBSの収録に映らないよう、カーソルと操作バーは表示しません。ホイールでの拡大も効きません。

**変更**

- 以前の見本講義は同梱しなくなりました。テストには本文のない骨組みだけを使います
- `npm run release` と配布の手順書は配布物から外しました

**すでにcloneしている方へ**

今回の更新でGitの履歴を作り直したため、`git pull` では更新できません。作成したスライド（`lectures/`）を別の場所へ退避してから、cloneし直してください。

以前の版で作ったスライドを戻すときは、`lecture.json` の指定を新しい名前に変更してください。`rules` は `sakusura` または `free`、標準デザインの `design` は `sakusura-standard` です。ブラウザに保存された表示設定は初期状態に戻ります。

## はじめる

1. Node.js **24以上**を用意します。
2. ZIPをすべて展開します。ZIPの中から直接起動しないでください。
3. Windowsでは `start-studio.cmd` をダブルクリックします。macOS / Linuxではこのフォルダーで `npm start` を実行します。
4. ブラウザで `http://127.0.0.1:4173/library` を開きます。

`npm install` は不要です。起動したターミナルは使用中も開いたままにしてください。Windows以外の環境は今回の配布検証の対象外です。

まずは同梱の「血液透析の仕組み」のどれかを開き、「無音リハーサル」で再生してください。配布ファイルに音声は含まれません。

## できること

- 文字・図形・画像の編集、スライドの挿入・複製・並べ替え
- 挿入元のデザインを保持するか、挿入先に合わせるかの選択（既定は挿入元を保持）
- 講義のフォルダー整理とゴミ箱からの復元
- デザインのサムネイル一覧、検索、フォルダーへのドラッグ移動
- PDFからのデザイン取り込みとページ・文字・位置・サイズの編集
- 全画面発表、無音リハーサル、録画モード、JPG・PDF・MP4の書き出し
- 全画面発表中の操作バー、レーザーポインター（L）、ペンと5色の切り替え（P・1〜5）、拡大（Z・ホイール）、スライド一覧（G）

保存済みの最新版デザインを **Template** の名前で同梱しています。12ページの見本・人物紹介・4種類の図解・調整済みの余白を含みます。標準デザイン **SAKUSURA Standard** も付属します。

スライド（講義）は、同じテーマを複数のLLMで作り比べた見本4本（血液透析の仕組み。音声なし）だけが入っています。不要なら `lectures/` から削除できます。カテゴリは空の状態で始まります。カテゴリは「デザイン」画面の「カテゴリごとのデザイン設定」で追加でき、追加したカテゴリはスライド一覧の分類と編集画面の選択欄に表示されます。テスト用の見本講義は `tests/fixtures/lectures/` にあり、`npm test` の実行中だけ `lectures/` に置かれます。

## 機能ごとの準備

| 機能 | 必要なもの |
| --- | --- |
| 編集・通常の再生・発表 | Node.js 24以上とブラウザ |
| PDFからデザインを取り込む | PythonとPyMuPDF（`python -m pip install PyMuPDF`） |
| MP4 / JPGを書き出す・ブラウザ検査 | ChromeまたはEdge。MP4には追加でffmpeg |
| ナレーションを生成する | 自分のGemini APIキーと、自分のプロジェクトのカスタムボイス |
| Orcaの画像Task連携 | Orca CLI（通常の編集・発表には不要） |

PDF変換は `python -c "import fitz"` で準備を確認できます。複数のPythonがある場合は、PyMuPDFを入れた実行ファイルを環境変数 `PYTHON_PATH` に指定できます。Chrome / Edgeは `CHROME_PATH` で指定できます。

## 音声は未設定です

**APIキー・`.env`・作成者の登録済みボイスID・既存の音声は同梱していません。** APIキーがなくても編集・発表・無音動画の書き出しができます。

音声を使う場合だけ、自分のPCで以下を設定します。

1. 自分のGemini APIキーを取得します。
2. このフォルダーに `.env` を作り、`GEMINI_API_KEY=自分のキー` を記入します。
3. `npm run voices` で自分のプロジェクトの声を確認し、`npm run voices -- --resolve --name "ボイス名"` で設定します。
4. スタジオを起動し直します。

APIキーをチャット・スクリーンショット・GitHubに貼らないでください。`.env` とローカル設定はGitの追跡対象から除外しています。ナレーションの生成を実行すると、その原稿をGemini APIに送信し、API利用料金が発生します。通常の編集・PDF変換・無音再生ではTTS APIを呼び出しません。

## 開発・検証

```sh
npm test
npm run qa:browser -- --lecture <講義のフォルダー名>
```

ブラウザ検査にはChrome / Edge、PDF検査にはPython / PyMuPDFが必要です。`.github/workflows/ci.yml` でWindows上の自動テストを実行します。自分で追加したスライドや教材は、`.env`・`reports/` とともにGitの追跡対象外です。

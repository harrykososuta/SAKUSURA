# 血液透析の仕組み — 参照資料

確認日：2026-10-24。血液透析の入門スライド1枚。音声は生成していません。

- [NIDDK: Hemodialysis](https://www.niddk.nih.gov/health-information/kidney-disease/kidney-failure/hemodialysis) — 体外循環、半透膜の両側を流れる血液・透析液、逆向きの流れ。
- [National Kidney Foundation: Hemodialysis](https://www.kidney.org/kidney-topics/hemodialysis) — 拡散による小分子老廃物の除去、限外濾過による除水。
- [Intermountain Health: Living with Kidney Disease, p.24](https://intermountainhealthcare.org/ckr-ext/Dcmnt?ncid=529755748) — 拡散の濃度差、限外濾過の圧力差。

導入説明として、老廃物は尿素を例にしています。膜を通る物質の移動方向は、実際には物質ごとの濃度差などに依存します。

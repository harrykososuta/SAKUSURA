# 動画にする（自動書き出し / OBS）

## 自動で書き出す（おすすめ）

```powershell
npm run render -- --lecture <講義名>      # → exports/<講義名>_001.mp4（次は _002.mp4 …）
```

- **サムネイル**：再生画面の「サムネイルをJPGで保存」で、1枚目を動画と同じ見た目の 1920×1080 JPG（約200KB）としてダウンロードできます。進行バーは写りません。ターミナルでは `npm run thumbnail -- --lecture <講義名>`（`exports/<講義名>_thumbnail.jpg` に上書き保存）。
- **ボタンでも書き出せます**：再生画面（`npm start`）の「動画を書き出す」を押すと、同じ処理をサーバー側で実行します。進み具合（%）が画面下に出て、完了すると「書き出し先を開く」で exports フォルダーを開けます。書き出し中も画面・PCは自由に使え、画面を閉じても書き出しは続きます（再び開くと進み具合が表示されます）。同時に書き出せるのは1本までです。ボタンは全スライドの音声が揃うと押せます。

- 画面を出さないブラウザで、録画モードの画面（1920×1080）を要点が現れる段階ごとに撮り、生成済みの音声と同じ時間割で並べてMP4（H.264 / AAC 48kHz、30fps）にします。リアルタイムで再生しないので、10分の講義で約5分です。
- 要点が現れるところは0.28秒のフェード、スライドの切り替えはカットです。最終枚は音声のあと2秒止めて終わります（`--tail 秒` で変更）。
- 事前に全スライドの音声が必要です（未生成なら止まります）。未生成の画像は「画像生成待ち」の枠のまま書き出し、注意を表示します。
- ffmpeg が必要です（`winget install Gyan.FFmpeg`）。見つからないときは `FFMPEG_PATH` に ffmpeg.exe の絶対パスを指定します。
- 書き出すたびに番号を1つ増やした新しいファイルになり、前の動画は上書きせずに残ります（いちばん大きい番号が最新）。
- 途中の画像は `reports/<講義名>/render/` に作り、完了後に消します（`--keep` で残す）。

# OBSでの収録

OBSは画面をそのまま録るキャプチャーです。自動書き出しを使えない場合や、操作しながら録りたい場合に使います。

## 最初の設定

1. `npm start` でプレイヤーを起動し、ChromeまたはEdgeで開きます。
2. OBS「設定 → 映像」の基本キャンバスと出力解像度を **1920×1080**、FPSを **30** にします。
3. ソースに「ウィンドウキャプチャ」を追加し、プレイヤーのブラウザを選択します。
4. 音声は「アプリケーション音声キャプチャ」で同じブラウザを指定するか、対応するOBSでウィンドウキャプチャの音声取り込みを使います。
5. 同じブラウザ音声を複数ソースで取り込まないようにします。アプリ別で取り込む場合はデスクトップ音声を無効にします。不要なマイクもミュートします。
6. 出力の録画形式を設定します。MKVで録画後、OBS「ファイル → 録画の再多重化」でMP4にする方法も使えます。

## 収録の順序

1. production Harnessを通し、音声と画面を確認します。
2. ブラウザで講義を選択し「最初から」を押します。無音リハーサルのチェックを外します。
3. Fまたは「全画面プレゼン」ボタンを押します。Chromeのヘッダーと操作画面が隠れ、スライドが最大に拡大されます。16:9以外の画面では比率を保った黒帯が入るので、OBSのプレビューで取り込み範囲を確認します。
4. OBSで録画を開始します。
5. プレイヤーのブラウザを前面に戻し、Spaceで再生します。Spaceの前にマウスを動かすと約2.5秒カーソルと操作バーが出ますが、Spaceを押すと消え、再生中はマウスを動かしても出ません（Lを押したときだけレーザーポインターが映ります）。Pのペンの線とZの拡大も録画に映ります。Gのスライド一覧は再生を一時停止し、一覧の画面が録画に映ります。ホイールでの拡大は再生中は効きません。
6. 最終枚で停止したら、OBSの録画を停止します。Escで録画モードを解除できます。

本番前に10秒程度を録画し、保存されたファイルに映像と音声が入っているかを確認してください。

## OBSブラウザソースを使う場合

URLに `http://127.0.0.1:4173/?lecture=demo&record=1`、幅1920・高さ1080を指定できます。ただし、これは通常ブラウザとは別のプレイヤーです。通常ブラウザ側の再生ボタンでは制御できません。OBS側の「対話」から操作し、音声の出力先もOBSで設定してください。

初期構成では通常ブラウザのウィンドウキャプチャを使います。OBS録画の自動開始・終了、遠隔操作、ブラウザとOBSソース間の同期は含みません。

公式資料: [アプリケーション音声キャプチャ](https://obsproject.com/kb/application-audio-capture-guide)、[ブラウザソース](https://obsproject.com/kb/browser-source)、[録画設定](https://obsproject.com/kb/standard-recording-output-guide)。

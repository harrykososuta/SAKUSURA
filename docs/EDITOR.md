# ブラウザでスライドを編集する

`npm start`（または `start-studio.cmd`）で起動し、通常画面の「スライドを編集」を押します。
直接開く場合は **http://127.0.0.1:4173/editor**。`?lecture=my-lecture` のように講義を指定できます。
プログラム更新後はサーバーを再起動してください。

## 基本操作

- 画面上部のメインメニュー（ライブラリ／編集／デザイン）で、どの画面からでも行き来できます。ライブラリでは、カテゴリとフォルダーでスライドを探せます。講義の分類・整理は [LIBRARY.md](LIBRARY.md) を参照してください。従来の選択欄もカテゴリ・フォルダーごとのグループ表示で使用できます。

- ヘッダー左の **メインメニュー（ライブラリ／編集／デザイン）** で画面を行き来できます（ロゴを押してもライブラリへ戻れます）。右側は「保存の状態」「再生（新しいタブ）」「保存する」の順で、使う機会の少ない「JSONを控える」は **「︙」（その他の操作）** の中にあります。
- 編集するスライドは、ヘッダーの **「スライド」** を押して選びます。ライブラリと同じカテゴリ・フォルダーの構成で開き（最初は表示中のスライドの場所）、左のツリー・上の現在位置・検索（スライド名・演題番号・フォルダー名）から探せます。クリックで選んで「開く」、またはダブルクリック／Enter で開きます。↑↓で選択、Backspace で上のフォルダーへ戻れます。未保存の変更があるときは、切り替える前に確認します。
- 左の一覧からページを選択。中央の見出し・本文・画像をクリックすると右に設定が表示されます。
- 一覧とキャンバスの境界をドラッグすると、一覧の幅を140〜480pxで調整できます。幅はこのブラウザに保存されます。境界のダブルクリックで初期幅に戻せます。境界にフォーカスして左右キーでも調整できます。右の編集パネルの幅も、パネル左端の境界で同じように調整できます（260〜720px）。
- ドラッグで移動。右下のハンドルで幅を変更（画像は幅と高さ）。数値入力でも調整できます。
- 文字をダブルクリックすると、その場で編集できます。クリックして右側の文章欄から編集する方法もあります。
- `**重要語**` で既存の強調書式を使います。文字の色とサイズ、ロゴ、フッターは共通書式を維持します。
- 要素を選択し、矢印キーで1px、Shift＋矢印で8px移動できます。ドラッグ時の8px吸着は上部で切り替えられます。
- 右の「講義のカテゴリ（全スライド共通）」でシリーズの配色を切り替えます。変更はその講義全体に適用します。既存データの未指定値は、ユーザーが選ぶまで維持します。
- 「左揃え」「中央」「右揃え」はスライドの本文領域を基準に配置します。
- 「選択した文字・画像の配置を元に戻す」で選択要素だけ、「このスライドの配置を元に戻す」でそのページ全体の配置を戻せます。
- 元に戻す／やり直しは上部のボタン、または入力欄の外で Ctrl+Z／Ctrl+Shift+Z（Ctrl+Y）。履歴は最大100操作で、ページをまたいで使えます。再読み込みで履歴は消えます。
- **「保存する」または Ctrl+S で保存**します。自動保存はしません。未保存での講義切り替えや画面を閉じる操作には確認が出ます。

## スライドの挿入・コピー・並べ替え（PowerPointと同じ操作）

左のスライド一覧で、PowerPointのスライド一覧と同じようにページを足したり、動かしたり、消したりできます。

- **スライドを挿入**：一覧の上の「＋ 挿入」、または一覧を右クリックして「スライドを挿入…」を選びます。次の3つを選びます。
  - **挿入元の講義**：ライブラリにあるどの講義からでも選べます。編集中の講義も選べます。
  - **ページ**：ページの絵をクリックして選びます。Shift＋クリックで範囲を選べ、「ページ指定」に `3, 5-7` のように番号を入れても選べます。ダブルクリックすると、その1枚だけをすぐ挿入します。
  - **挿入する位置**：「先頭（1枚目の前）」「◯枚目の後ろ」の中から、どこでも選べます。右クリックから開いた場合は、右クリックしたスライドの後ろが最初から選ばれています。
- **コピー・切り取り・貼り付け・複製**：一覧でスライドを選び、Ctrl+C・Ctrl+X・Ctrl+V・Ctrl+D を押すか、右クリックメニューから選びます。貼り付けは、選んでいるスライドの後ろに入ります。コピーしたスライドは、ヘッダーの「スライド」で**別の講義に切り替えてから貼り付けても**使えます。
- **複数選択**：Ctrl＋クリックで1枚ずつ、Shift＋クリックで範囲を選べます。コピー・削除・移動は、選んだスライドすべてに働きます。
- **並べ替え**：一覧でドラッグすると、差し込む位置に線が出ます。Ctrl+↑／↓、または右クリックの「前へ移動」「後ろへ移動」でも動かせます。
- **削除**：Delete、または右クリックの「削除」で消します。すべてのスライドを消すことはできません。
- どの操作も、元に戻す（Ctrl+Z）で戻せます。

**画像と音声**：挿入・貼り付けしたスライドには、新しいID（その講義で使っていない番号）が付きます。**保存するとき**に、元のスライドの画像・ラベル位置・音声が新しいIDのファイル名でコピーされます。保存するまでは、元の講義の画像をそのまま表示します。原稿・声・話し方・モデルが元と同じなら音声はそのまま使えるので、作り直し（課金）は要りません。原稿を直したときは、そのスライドだけ音声を作り直します。元の講義のファイルは変わりません。

**デザイン**：挿入したスライドは、貼り付け先の講義のデザイン・カテゴリで表示されます（PowerPointの「貼り付け先のテーマを使用」と同じ）。

**枚数と並びのルール**：SAKUSURAの構成（合計12枚・一文スライド2枚・1枚目サムネイル・最後はTake Home Message など）は、**講義を生成するときのルール**です。この画面でスライドを挿入・削除・並べ替えした講義には `slidesEdited: true` が付き、保存とHarnessで枚数・並びの検査をしなくなります。演題番号・カテゴリ・強調記法 `**` の検査は続きます。総尺の目標（`targetSeconds`）との差は、Harnessの本番検査（`--production`）で引き続き確かめます。

## 図形・文字の追加

上部の「追加」から **文字・四角・丸・矢印・線** をスライドに足せます。足した要素はドラッグで移動、右下のハンドルで大きさを変更し、右の編集パネルで色・文字の大きさ・角度・位置を数値で調整します。

- 色と文字サイズは共通デザインの中からだけ選びます。文字は濃いグレー／薄いグレー・28px（本文）／40px（見出し）、線と図形は紺／オレンジ（講義のカテゴリの配色）です。`**語**` で太字にできます。
- 文字はダブルクリックでその場で編集できます。四角・丸は枠の近くだけをつかめるので、内側の文字はそのままクリック・ダブルクリックで編集できます。
- 矢印・線は角度（−180〜180度）で向きを変えます。
- 選択して Delete（または右の「この図形・文字を削除」）で削除します。元に戻す／やり直しも使えます。1枚に12個までです。
- **表示タイミングは任意**です。未設定のまま保存すると、スライドの最初から表示します。ナレーションに合わせて出す場合は、本文と同じく秒数または「試聴中の時刻に合わせる」で決めます。「タイミングを外す」で未設定に戻せます。
- **足した文字は読み上げません。** 音声はそのまま使えます。読ませたい場合は、ナレーション欄の原稿にその言葉を足し（前の表示タイミングがずれないよう、なるべく原稿の最後）、そのスライドだけ音声を作り直して表示タイミングを確認します。Claudeに「◯枚目の『△△』を読んで」と伝えても同じ手順で進めます。
- 最終チェック（Harness）は、**ナレーションで読まれていない追加文字**と**表示タイミング未設定の図形・文字**を「要確認」として知らせます（エラーにはしません）。`reports/<slug>/harness.md` の「追加した図形・文字の確認」にも載ります。
- スライドの外・左端の帯・SAKUSURA・ページ番号・表題へのはみ出しや、追加した文字と見出し・本文の文字の重なりは、ブラウザ検査がエラーにします。

## 音声・タイミング

### 動き・ビルドアップ

右の **「このスライドの設定」→「動き・ビルドアップ」** で、ページに合う動きを選べます。

- **軽快な出現**：0.25秒のフェードと20pxの移動・小さな拡大。同時に出す項目は0.09秒ずつずらせます。
- **全体を予告**：未説明の位置に点線の枠を置き、表示タイミングに合わせて中身を埋めます。
- **説明中に注目**：全体を見せ、説明中以外を35%に薄くします。同じ時刻の項目は一緒に注目します。
- **矢印 → 要素**：フロー図で選べます。矢印が伸びてから先の箱が現れます。既存の経路指定は保ちます。
- **上限で停止**：棒グラフで選べます。教材の実際の上限値を入力すると、その位置の点線で棒が止まり、超過時に×が出ます。要求値は残して併記します。「上限超過後に薄くする項目」だけを薄くできます。
- **動きなし**：表示時刻で即時に切り替えます。「おまかせ」はAI Topicで短い動き、医療系では従来の表示を使います。

本文を選ぶと **「この項目の演出」** から、表示後の✓／×を指定できます。フロー図の2項目目以降では、その項目へ向かう矢印の実線／点線と通過／遮断も選べます。判定の意味は教材の内容に合わせて指定してください。

**「無音で動きを確認」** はAPIキー・音声ファイルなしで使えます。予定時間（音声がある場合はその長さ）で表示位置を進め、もう一度押すと停止します。下のスライダーで任意の時刻へ戻せます。「再生位置に合わせて表示」を外すと、通常の全要素表示へ戻ります。保存した動きは通常再生・全画面の手動送り・無音動画にも反映されます。

画面下で保存済みWAVを試聴します。スライダーは音声の `currentTime` を基準にし、未生成の場合も表示位置を手動確認できます。
通常の編集では全要素を表示。「再生位置に合わせて表示」を選ぶとcueによる段階表示を確認できます。
本文を選び、右側の秒数または「試聴中の時刻に合わせる」でcueを調整します。

**メインのナレーション欄には、実際に音声生成に使う原稿を表示します。** 読み補助原稿 `ttsText` があるページではその文章、ないページでは `narration` を編集します。読み仮名もこの欄で修正できます。
`ttsText` のあるページの「表示用の原稿」は、再生画面の原稿欄に使う文章です。ここだけを変えても音声は変わりません。
発話原稿を変更すると古い音声の試聴は無効になります。

音声を更新するには、範囲を「このスライド」または「変更・未生成のスライド」から選び、「音声を生成・更新」を押します。
原稿を保存したうえで対象枚数・文字数・声を表示します。この確認だけではAPIを呼びません。
内容を確認し、**「生成を開始」** を押すとGemini TTSを呼びます（利用料金がかかります）。完了後、そのまま試聴できます。
確認後に原稿・音声設定が変わった場合は再確認が必要です。失敗時に自動再試行はしません。
更新前のWAVと生成条件は `audio/backups/` に残します。新しい音声で表示タイミングが範囲外になった場合は、生成後に調整してください。
CLIの `npm run tts -- --lecture <slug> --check` と差分生成も引き続き使えます。CLIと画面の生成は同じキャッシュとロックを使用します。
配置・見出し・本文・cueの変更だけならTTSは再生成しません。声は従来どおり **clonevoice** です。

## 保存と互換性

講義の `lecture.json` に保存し、配置だけ `slides[].placement` として追加します。
配置情報のない講義は従来のCSSのまま表示されます。同じ描画処理を編集・再生・動画出力で使います。
既存の画像・WAVを保存操作で変更することはありません。挿入・貼り付けしたスライドの画像・音声は、保存時に新しいIDのファイルとして追加します（保存済みのスライドのファイルは上書きしません）。

保存時に構成・値を検証し、保存前のJSONを `lectures/<slug>/backups/lecture-<日時>-<識別子>.json` に残します。
別の編集画面や外部ツールで変更された場合は、古い版からの保存を拒否します。
その場合、上部の「JSONを控える」で編集中データをダウンロードしてから再読み込みし、変更を照合してください。
### 保存履歴を比較・復元する

ヘッダーの **「︙」→「保存履歴を比較・復元」** で、保存前の版（最新200件）を選べます。履歴がない場合は、内容を変更して保存すると最初の履歴が残ります。

- 選んだ履歴と現在の編集内容（未保存の変更も含む）を、ページの絵と変更箇所の表で見比べます。原稿・本文・画像・配置・図形・cue・並び順と講義全体の設定を確認できます。
- **「このページを復元」** は、両方の版に同じIDで存在するページだけを戻します。他ページと現在の並び順は保ちます。削除済みページを戻す場合は全体の復元を使います。
- **「講義全体を復元」** は、選んだ版の内容と並びを読み込みます。既に付いた `slidesEdited: true` は外しません。
- 復元は編集画面へ読み込む操作です。**「保存する」で確定**し、保存前は **元に戻す** で取り消せます。復元後の保存も、その直前の内容をバックアップします。外部の変更との競合検査も通常の保存と同じです。
- 音声ファイルは戻しません。原稿を戻して音声条件が変わる場合は、音声の状態を確認して必要なページだけ更新します。画像は保存済みのファイルを参照します。外部ツールが元画像自体を上書きした場合は、その古い画像の見た目までは復元できません。

### 画像を追加・差し替え・トリミングする

上部の **「追加」→「画像」**、または画像を選んだ編集パネルの **「画像を差し替え・トリミング」** を押します。サムネイル（title）・要点（statement）・図と要点（figure）に対応します。

- PNG・JPEG・WebP（10MB以内・8000万画素以内）を選び、画像の説明を入力します。
- プレビューをドラッグして使う範囲を選ぶか、左・上・幅・高さを％で入力します。「画像全体を使う」でトリミングを戻せます。
- 構造ラベル付きの画像を差し替える場合は、各ラベルが指す構造をプレビュー上でクリックします。文字を置く向きも選べます。すべて指定し、ラベルがトリミング範囲内に入ると適用できます。
- **「画像を適用」→「保存する」** で確定します。適用後も元に戻す・やり直しができ、保存履歴から元画像を参照できます。画像は `images/upload-<UUID>.<拡張子>` に別名で保存し、元ファイルは上書きしません。適用した後に取り消した画像も、履歴からの参照を守るためそのまま残します。
- トリミングとラベル位置は講義JSONに保存し、編集・再生・MP4で共通の描画を使います。画像の変更だけでTTSは生成しません。

## 今回の範囲

文章・章名・配置・要素の幅・画像サイズ・台本・読み補助原稿・cue・予定秒数・次への余白を編集し、図形・文字（文字・四角・丸・矢印・線）を追加・削除できます。スライドの挿入（他の講義・この講義から）・コピー・貼り付け・複製・並べ替え・削除もできます。
画像のアップロード・差し替え・トリミングと保存履歴の比較・復元にも対応します。本文・画像・まとめの一文・追加した図形は、選択して上部の「選択要素を削除」または Delete／Backspace で削除できます。文字の入力中は要素を削除しません。元に戻す／やり直すに対応し、保存すると再生画面にも反映されます。
自由レイアウトでは対応する表示要素と不要になった表示タイミング・配置を削除し、同じグループの残りの本文は保持します。原稿や音声ファイルは変更しません。見出し、およびレイアウトを成立させるために必要な要素は削除できません。本文ブロックの追加と白紙のスライドの新規作成は今後の拡張です。
画像の制作とMP4出力は従来の制作フローを使用します。
配置後のはみ出し・重なりは `npm run qa:browser -- --lecture <slug>` と画面PNGで確認してください。

## 検証

`npm test` は保存・TTS APIのOrigin制限、版の照合、バックアップ、不正な配置、TTSの範囲・文字数・差分・ロック・失敗時の表示を検査します。
`node tools/editor-delete-qa.mjs` は隔離した講義で、本文の削除ボタン・Delete／Backspace・入力中の保護・取り消し／やり直し・保存と再読み込み・再生画面への反映を検査します。
結果は `reports/editor/editor-qa.json` とPNGに保存します。元の講義には保存しません。

`npm run qa:motion` は隔離した6ページで、動きの設定・無音確認・保存、線→箱→判定、予告枠、フォーカス、上限での停止、巻き戻しとMP4用フレームの一致を確認します。`-- --render` を付けると無音MP4も書き出します。検証は `reports/motion/motion-qa.json` とPNG、見本動画は `exports/animation-patterns-preview_001.mp4`（以後番号を増やす）です。

## AIツールと使う（変更の自動反映）

制作・大きな修正は、使い慣れたAIツール（Claude Code・Codex・Antigravity・Cursor・Orca など）をこのフォルダーで起動して依頼します。AIツールは `AGENTS.md`（Claude Code は `CLAUDE.md`）とスキルを読み、制作ルールに従います。
スタジオはAIツールを起動しません（ブラウザからPCのプログラムを動かす入口を作らないため）。スタジオは結果の確認と細かな手直しに使います。

AIツールや別の画面が `lecture.json` を変更すると、編集画面は自動で最新の内容を読み込みます（表示中のスライドと選択は保ちます）。
未保存の変更があるときは上書きせず、画面上部のお知らせから **「変更を破棄して最新を読み込む」** か **「このまま編集を続ける」** を選べます。
（このまま保存しようとすると、別の変更との衝突として保存を止めます。必要なら「JSONを控える」で控えてください。）

# 講義をカテゴリ・フォルダーで整理する

`npm start` または `start-studio.cmd` で起動すると、最初にスライドライブラリが開きます。
直接開く場合は **http://127.0.0.1:4173/library** です。どの画面からも、ヘッダーのメインメニュー（**ライブラリ／編集／デザイン**）で行き来できます。ライブラリの「編集」は、開いていたスライドの編集へ戻ります。

## カテゴリから探す

一覧の上部に **カテゴリのタブ**（すべてのスライド・各カテゴリ・ごみ箱）、その下に **現在地**（例：すべてのスライド › 営業研修 › 基礎編）と件数・検索・並べ替え・「＋ フォルダーを作成」が並びます。フォルダーを開いているときは、フォルダー名の右の **✎（名前を変更）・🗑（削除）** で操作できます。

カテゴリのタブは `designs/category-presets.json` の一覧（デザイン画面の「カテゴリごとのデザイン設定」で追加・削除）で、講義の `category` を使って自動分類します。一覧にないカテゴリの講義は「カテゴリ未設定」に入ります。
カテゴリのないデモなどは「カテゴリ未設定」に表示します。
「すべてのスライド」は、フォルダーの中も含む全講義を表示します。

画面上部のカテゴリタブ（すべての講義・各カテゴリ・ごみ箱）はスクロールしても固定です。
右側の **フォルダー** パネルは、PCのエクスプローラーのようなツリーです。カテゴリ・フォルダー名の左の矢印で開閉でき、開閉状態はブラウザに記憶されます。
カテゴリやフォルダーを開くと、その直下の子フォルダー（一覧の先頭）と講義が中央の一覧に表示され、ツリーもその場所まで自動で開きます。子フォルダーの行はクリックで開け、チェック・ドラッグ・「整理」で移動や削除もできます。
検索中は現在の範囲の子フォルダーの中も検索します。
講義名・説明文・演題番号（例：`#01`）・フォルダー名で検索でき、更新日・講義名・演題番号で並べ替えられます。

## フォルダーを作る

1. カテゴリを開き、「フォルダーを作成」を押します。
2. 名前と作成先を指定して「作成する」を押します。
3. 講義の行の **「整理」** から、そのフォルダーへ移動します。

フォルダーは8階層まで作成できます。たとえば `営業研修 / 新人向け / 基礎編` のように整理できます。
フォルダーを開くと名前を変更できます。

## ドラッグで移動する

講義の行やフォルダーを、移動先のフォルダーへドラッグします。
右側のフォルダーツリー、一覧上部のカテゴリタブ、現在地（パンくず）にドロップできます。
閉じたフォルダーの上でしばらく止めると、自動で開いて子フォルダーへドロップできます。
カテゴリ名（ツリー・タブ）へドロップするとカテゴリ直下に戻せます。

フォルダーの移動では、中の講義・子フォルダーもまとめて移動します。
自分自身や自分の子フォルダーには移動できません。
複数の講義はチェックボックス、複数のフォルダーはツリーで **Ctrl+クリック**（Shift+クリックでも可）して選択し、選択した項目をドラッグするか、**「移動先を変更」** からまとめて移動できます。
同じカテゴリのフォルダーを移動先に選べます。「カテゴリ直下」を選ぶとフォルダーから取り出せます。
講義のカテゴリ自体を変える場合は、編集画面の「講義のカテゴリ」から変更して保存します。
カテゴリが変わり、以前のフォルダーと一致しなくなった講義は、新しいカテゴリの直下に表示されます。

## 選択した項目を削除・復元する

講義をチェック、またはフォルダーをCtrl+クリックで選択し、**「選択した項目を削除」** を押します。Deleteキー、上部の「ごみ箱」タブへのドラッグ、フォルダー内の削除ボタンからも操作できます。
確認画面で、対象となる講義数・フォルダー数を確認してから実行します。
フォルダーを削除すると、中の講義と子フォルダーもまとめてごみ箱に入ります。

上部の **「ごみ箱」** タブから、1回の削除操作ごとに復元できます。複数選択での一括復元にも対応します。
元のフォルダー構成も復元します。元の親フォルダーがない場合はカテゴリ直下へ戻します。
復元先に同名フォルダーがある場合は、既存の名前を変更してから復元してください。

ごみ箱はこのアプリ内の機能で、Windowsのごみ箱とは別です。
削除中も元の講義ファイル・音声・画像は保持し、一覧・編集・再生の対象から外します。
完全削除は行いません。`input/` や書き出し済み動画にも影響しません。

## 編集・再生へ戻る

講義名または「編集」を押すとエディター、「再生」を押すと再生画面を開きます。
従来の講義選択欄も残し、カテゴリとフォルダーのパスをグループ見出しとして表示します。
別の画面で分類した後は、画面へ戻ったときに選択欄を更新します。
未保存の編集がある場合、ライブラリへ移動する前に保存してください。

## 共有する・受け取る

講義の行の **「共有」** で、ほかの SAKUSURA へ渡す共有ファイル（ZIP）をダウンロードできます。受け取った側は一覧上部の **「取り込む」** でZIPを選ぶか、ZIPを画面にドラッグします。
取り込んだ講義は **「共有で受け取った」** タブ（ごみ箱の左）に並び、行に送り主と版を表示します。講義のカテゴリは送り主のまま変えず、「整理」で自分のカテゴリ・フォルダーへ移すとこのタブから外れます。
同じ講義（共有ID）が手元にある場合は、取り込むときに「更新する」か「別に残す」を選びます。詳しくは [docs/SHARE.md](SHARE.md)。

## 保存場所とバックアップ

**このフォルダーは、スライドライブラリ内で使う分類用のフォルダーです。**
講義本体は `lectures/<slug>/lecture.json`、音声・画像は従来の保存先を使用します。
分類操作で講義本体や音声・画像を移動したり、講義のカテゴリ配色を変更したりすることはありません。

分類情報とごみ箱は最初の操作で **`library/index.json`** に保存され、ブラウザを閉じても残ります。
更新前の情報は `library/backups/index-<日時>-<識別子>.json` に自動保存します。
別の画面の変更が先行した場合は保存を止め、一覧を更新します。内容を確認して操作し直してください。
復元する場合は、サーバーを停止して現在のJSONを控えたうえで、対象のバックアップを `library/index.json` にコピーします。

この画面で扱うのは講義の分類・フォルダー・ごみ箱です。Windows全体のファイル操作や、講義本体の完全削除・複製・アップロードは扱いません。
従来の `/?lecture=<講義名>` は再生画面を開きます。講義を指定せず再生画面を開く場合は `/player` を使えます。

## 検証

`npm test` は分類の保存・復元、入れ子、名前変更、移動、ごみ箱、同名・不正値・カテゴリ違い・保存競合を検査します。
実講義のJSONが変わっていないことも確認し、結果とPNGは `reports/library/` へ保存します。
`npm run qa:share` は送り主・受け取り側の2つのスタジオを一時フォルダーで起動し、「共有」→ZIPのダウンロード→「取り込む」→受け取り箱→同じ共有IDの再取り込み→「整理」で外れる、までを画面で確認します（`reports/share/`）。

## 設定（配色など）

各画面のヘッダー右端の **歯車アイコン** から設定ページ（**http://127.0.0.1:4173/settings**）を開けます。

- **外観**：ライト・ダーク・システムに合わせる（Windowsの「個人用設定 › 色」に連動）から選べます。
- **アクセントカラー**：ボタンや選択中の色を、ネイビー（標準）・ティール・グリーン・パープル・ワイン・グラファイトから選べます。
- 外観・アクセントカラーを変えても、スライドのデザイン（紙色・カテゴリの色・文字）や書き出す動画・サムネイルは変わりません。
- **編集画面**：「8px刻みで移動」の初期値、原稿欄をたたんだ状態で開くかどうか。
- **ライブラリ**：一覧の並び順の初期値。
- **リセット**：スライド一覧の幅・フォルダーの開閉・原稿欄の開閉、またはすべての設定を初期状態に戻します。

設定はこのPCのブラウザ（localStorage）に保存され、講義データには含めません。別のブラウザで開いた場合は標準の設定になります。

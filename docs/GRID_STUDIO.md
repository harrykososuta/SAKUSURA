# Template

配布時は、このデザインの最新版を **「Template」** という名前で同梱します（ユーザー指定・2026-10-25）。保存済みプリセットのIDは `design-9122c0b9-ba34-486e-bcf8-0758a5f70d22`。9・10・12ページの余白調整も含め、配布準備時には保存済みの最新編集内容を引き継ぎます。

SAKUSURA Standardの配色に、無地の背景・四隅の二重かぎ括弧『』・縦の見出しマーカーを組み合わせたプリセットです。方眼紙・閉じた外枠・チャンネル登録・動画サイトの操作表示は含みません。

「デザイン」一覧の **Template** →「編集」で開きます。詳細のスライド一覧も見本の横に配置しています。左の12ページから選び、中央の文字をクリックして編集できます。構成欄の「配置パターン」で図解の型を切り替えられます。

| 配置パターン | レイアウト | ブロック数 | 用途 |
| --- | --- | --- | --- |
| profile | figure | 4 | 左に名前と経歴、右に大きな人物写真 |
| system | flow | 7 | 入口・処理・実行の3領域 |
| lanes | flow | 4 | 役割を横のレーンで分ける |
| journey | timeline | 4 | 4段階の時間軸 |
| recovery | flow | 8 | 停止・再開の2行比較 |

人物紹介の画像は差し替え用のベクター見本です。実際の人物情報や写真ではありません。図解の箱・見出し・説明はHTMLで描き、見本文字の編集に対応しています。

講義でこの配置を使う場合は、同じテーマCSSを使い、各スライドに `composition` と上表のレイアウト・ブロック数を指定します。`blocks[].label/text/detail` と `cues` は通常と同じです。`animation.type` を `subtle` にすると、矢印を描いてから要素を表示します。描画は音声位置から計算し、巻き戻しと動画フレーム描画で復元します。

`npm run new -- --design <ID> ...` はテーマCSSを取り込みます。デザイン編集画面の見本12ページ・見本文字・配置パターンをそのまま講義へコピーする機能ではありません。講義を作るときは選んだ構成に合わせて配置を指定します。

元のCSSは `designs/grid-studio.css`。`node tools/grid-studio-design.mjs` は未登録時だけプリセットを作り、既存時はIDを表示します。`--update` はCSSと見本を初期内容で更新するため、画面でカスタマイズしたプリセットには使わないでください。

確認は `node tools/grid-studio-qa.mjs`。見本12ページ、共通16レイアウト、編集画面、矢印と要素の順序、巻き戻しを確認し、`reports/grid-studio/` にPNGと検証結果を残します。
